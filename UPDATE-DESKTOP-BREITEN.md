# Gleichmäßige Breiten der Desktop-Startseite

Alle Hauptabschnitte der Startseite (Kopfbereich, Suche, Aktuelles, Schnellzugriff, Diese Woche) verwenden am PC nun dieselbe maximale Breite von 1200 px. Darin enthaltene Listen und Karten füllen diese Spalte. Auf schmalen Bildschirmen bleibt das bisherige Layout bestehen.

Keine Änderung an Inhalten, JSON-Dateien oder Worker erforderlich.
